## 📁 Project Structure

```
├── gamemodes/          # Gamemode source files (.pwn, .amx)
│   ├── Smit.pwn        # Main gamemode source
│   └── Smit.amx        # Compiled gamemode
├── include/            # Include files for Pawn
├── plugins/            # Server plugins (.so/.dll)
├── filterscripts/      # Filter scripts (archived)
├── scriptfiles/        # Server data files
├── pawno/              # Pawno editor (archived)
├── npcmodes/           # NPC modes (archived)
└── EVEBASE35403.sql    # MySQL database structure
```

## 🚀 Installation / Установка

### Requirements / Требования

- SA-MP Server 0.3.7
- MySQL Server 5.5+
- Linux or Windows server

### Steps / Шаги

1. Download and extract SA-MP server 0.3.7
2. Copy the gamemode files to your server
3. Import `EVEBASE35403.sql` to your MySQL database
4. Configure database connection in the gamemode
5. Extract the archived files (filterscripts.zip, pawno.zip, npcmodes.zip)
6. Start the server

---

1. Скачайте и распакуйте SA-MP сервер 0.3.7
2. Скопируйте файлы мода на ваш сервер
3. Импортируйте `EVEBASE35403.sql` в вашу базу данных MySQL
4. Настройте подключение к базе данных в геймоде
5. Распакуйте архивные файлы (filterscripts.zip, pawno.zip, npcmodes.zip)
6. Запустите сервер
